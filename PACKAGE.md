# RecursiveAI.OneLlm

**LLM inference and agent runtime for .NET.** Provider clients for Anthropic, OpenAI and Gemini, one message model, a layered model catalog with decimal line-item pricing, and a happy-path API. The core depends on the base class library, OneYaml and OneImage only, and is trim and NativeAOT safe on its main paths.

OneLLM is unaffiliated with the `onellm` package on PyPI and with the OneLLM research model.

Source, documentation and issues: https://github.com/recursive-ai-oss/onellm-csharp
